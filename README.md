# 一介凡人

以《凡人修仙传》世界观为背景的修仙人生模拟。随机降生，一世修行，从人界走到灵界，再走到仙界。

参考了 [1in8b.life](https://1in8b.life/zh-hans/) 的「随机出生、活完一生」框架；界面、文案、数值与事件为本作原创，原著专有名词仅作同人致敬。非官方同人作品，不使用原著正文。

## 在线试玩

GitHub Pages（静态版）：<https://wang1375830242.github.io/yijie-fanren/>

GitHub Pages 只能运行静态文件，因此在线版的碑林是“本机模式”；点灯、留言只存在你的浏览器。要启用公共碑林，需要把仓库放到一台能运行 `server.py` 的机器上。

## 怎么打开

推荐用本地服务器启动：它会同时提供静态页面和公共碑林 API。直接双击 `index.html` 也能玩，但碑林会退化成“本机模式”。

Windows：

```bat
start.bat
```

或者手动：

```bat
cd yijie-fanren
python server.py
```

然后打开 <http://127.0.0.1:8765/>。

没有构建步骤，没有 npm 依赖，没有外部字体、CDN 或第三方统计。游戏本身断网也能玩；公共碑林需要 `server.py` 保持运行。

## 这一世怎么算

- **灵根**：天灵根、异灵根、双灵根、三灵根、四灵根、伪灵根、凡骨。决定修行速度，不决定上限。
- **境界**：炼气 → 筑基 → 结丹 → 元婴 → 化神 →（飞升）炼虚 → 合体 → 大乘 →（飞升）真仙 → 金仙 → 太乙 → 大罗 → 道祖。原著“渡劫期”在本作压缩进大乘后期，`m_ascend` 作为大乘→真仙的渡劫事件。
- **寿元**：每个境界有寿元上限。修为满了要冲关，冲关失败会掉修为，也可能道消。
- **行动**：苦修、游历、炼丹、宗门、参悟、蛰伏。不同重心影响修为、心境、灵石、悟性与遇事概率。
- **抉择**：事件会停下来问你一句话。风险选项可能当场要命，也可能在三百年后回来找你。
- **濒死抉择**：致命选项失败后先进入一次濒死结算，可按任务选择玉符、舍财或拼死；玉符也不是必活，失败仍会死。天劫、寿元耗尽、突破爆体等保留直接死亡。
- **文本阶段**：童年、凡俗、炼气、结丹、元婴、灵界、仙界分别使用不同事件池；进入后期后，前期童年/凡俗心境不会混进来。
- **心性倾向**：仁厚、狠辣、好奇、冒险、沉静会随选择累积，并影响后续事件的抽取概率；角色面板会显示当前主导心性。
- **童年选择**：100 组童年选择，其中 84 组按 14 种出身匹配，不是每局都“搭把手/装作没看见”。
- **旁白小事件**：等待选择时每隔几秒出现当前阶段的随机场景，不会一直干等。
- **场景**：事件文本按“场景 + 细节 + 余韵”组合，另有按阶段划分的旁白与环境池。
- **柔化模式**：降生页或 ⋯ 菜单可开。只柔化血腥/死亡措辞，不改变剧情与数值。
- **因果**：杀过的人、救过的人都会记着。业障重了，会在你最虚的时候上门。
- **灵石**：买、捐、行贿类选项会检查余额；没有灵石时不能硬选。捐灵石可以用滑杆选数量，也可以直接“全部”。
- **道侣**：结为道侣/成亲后，后续会持续出现与对方有关的事件；对方不是只出现一次的数值。
- **道侣线**：道侣会自行修炼、突破、寿尽；同界有日常交集，异界有书信，情分会随选择变化。
- **事件池**：3064 条组合事件（约 220 个场景模板，含约 320 条道侣相关事件）；同世文本加入去重与结果变体，避免同一世反复出现同一句。
- **飞升**：化神之后渡空间节点入灵界，大乘后期经历本作合并的渡劫阶段（九道天雷）入仙界。失败就是死；雷劫描写为本作二创，不冒充原著原文。
- **问心**：五岁、十五岁、三十岁、五十岁、七十岁各问一次；灵界/仙界开局另有一次“此身”之问。

有人停在炼气，有人筑基、结丹，也有人走到元婴、化神。飞升是另一回事。能证道道祖的，更少。

## 人物、宗门与灵根

万宝阁是设定资料馆，收录了 **95 条人物/角色条目、45 个宗门/势力、18 条灵根/体质/功法资料**，覆盖人界、灵界、仙界。人物和设定参考公开读者 wiki 与原著读者整理；原著没有明写的最终境界、归属或结局，标为「推测 / 读者共识」，不冒充官方设定。图鉴人物目前不直接作为每局 NPC，玩法事件以原创/程序化事件为主。

主要资料源：[凡人修仙传 Wiki（读者整理）](https://www.weqoocu.cn/fanren-wiki/)。

## 数据与隐私

没有账号，没有埋点。人生记录、速度、柔化模式偏好存在浏览器 `localStorage`：

- `yijie.lives.v1` — 人生记录
- `yijie.prefs.v1` — 速度、柔化模式等偏好
- `yijie.messages.v1` / `yijie.candles.v1` — 只在本机模式下使用的留言与灯数

公共碑林：通过 `server.py` 启动时，点灯和留言写入 `data/hall.json`，对所有访客可见；只打开静态文件时，则只存在本机。公共留言是公开的，请不要写真实个人信息。留言没有账号删除功能，部署前请考虑审核/清理策略。
