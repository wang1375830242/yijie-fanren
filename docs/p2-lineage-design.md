# P2：转世谱系与遗愿

日期：2026-10-23  
状态：第一版已实现

## 一、谱系

新增：

```text
yijie.lineage.v1
```

结构：

```js
{
  v: 1,
  total: 25,
  streak: 25,
  bestStreak: 25,
  entries: [/* 最近 20 世，最新在前 */]
}
```

每世记录：

- 世次 `no`
- 姓名
- 界域、境界
- 死因
- 宗门
- 道侣姓名
- 弟子姓名（最多 3 个）
- 遗愿
- seed、时间戳、lifeKey

`total` 独立累计，不会被 20 条上限截断。旧版本没有谱系时，按已有碑数回填总世次，不追造旧遗愿。

## 二、遗愿

死亡时由 `wishSummary()` 生成，优先级：

1. 失去道侣 / 道侣离散
2. 宗门失守（有入门记录且后来离开）
3. 人界有修为但未飞升
4. 因果未清或仍有在世对手
5. 兜底：还有一段路没走完

每世必定有一个遗愿。终局页显示：

```text
遗愿：……
```

## 三、终局

终局副标题显示：

```text
…… · 第 N 世
```

`N = 写入前 total + 1`，不使用人生记录条数，避免清档或导入后编号漂移。

## 四、碑林

新增两项跨局统计：

- **已读碑**：打开碑文时按 id 去重记录
- **世连续**：当前谱系累计世数

清空自己的碑会同时清理谱系与已读记录。导出/导入 JSON 也会携带 `lineage` 与 `steles`。

## 五、验收

- 连续写入 25 世，谱系只保留最近 20 条，但 `total=25`
- 最新一条世次为 25
- 失去道侣会生成「未守住道侣」遗愿
- 人界未飞升会生成「未飞升」遗愿
- 终局显示第 N 世与遗愿
- 碑林显示已读碑与连续世数
- 打开碑文后已读数增加
- 旧档缺少谱系时正常回退
- 220 局回归无异常
