# 自动突破与破境动画

日期：2026-10-23  
状态：已实现

## 规则

修为达到当前境界上限后，不再弹出「即刻冲关 / 再缓几年」的选择框。

流程改为：

```text
修为圆满
  ↓
自动冲关
  ↓
播放破境 / 功亏动画
  ↓
动画结束
  ↓
继续后续事件或下一回合
```

突破动画播放期间：

- `paused = true`
- 清除普通计时器与自动抉择计时器
- 不推进 `sim.step()`
- 动画结束后才恢复 `schedule()`

## 动画

复用全屏过场：

- 成功：显示「破 境」与旧境界 → 新境界
- 失败：显示「功 亏」与「冲关未成」
- 化神→炼虚、大乘→真仙：额外显示「飞升」，动画结束后切换主题

## 行为变化

- 不再有「再缓几年」的等待操作
- 破境结果仍由原突破概率决定
- 突破失败仍可能走火入魔
- 动画可点击「继续」跳过
- 动画结束后若已死亡，再进入终局

- 不再调用手动的 `openBreak()`
