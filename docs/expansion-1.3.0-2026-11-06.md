# 1.3.0 扩展 · 因果、天劫与短码

日期：2026-11-06

## 前世因果闭环

- 每世结束时，未了遗愿作为 `cause` 带入下一世
- 下一世最多触发一条三步因果链
- 因果类型：道侣、宗门、飞升、因果、未完成
- 每步两个选择，可在最后一步「了结」或「放下」
- 完成后写入 `causeDone`，不再传给下一世
- 旧存档没有 `legacyCause` 时完全不触发

## 突破天劫事件链

在筑基、结丹、元婴、化神前各插入一场主动抉择：

- 硬渡：较高风险，较高准备
- 借宝：消耗灵石，稳定准备
- 闭关：消耗时间，补悟性与准备

事件不改变原有破境公式，只影响准备与代价；真正的破境仍走原流程。

## 道统后段分支

元婴后，每条道统二选一：

| 道统 | 分支 |
|---|---|
| 剑锋 | 剑心 / 无拘 |
| 丹鼎 | 丹道 / 济世 |
| 阵心 | 守阵 / 杀阵 |
| 游侠 | 远游 / 归乡 |

每个分支再补两条后续事件，共 20 条分支事件。分支只写入 `pathBranch` 与少量心性/资源效果，不新增基础 Build 公式。

## 人生卡短码

- `js/life-code.js` 将核心人生字段压缩成 URL-safe 短码
- `life.html?c=...` 只读回放
- 支持下载命格卡、分享命格卡、同 seed 再开一世
- 账号页每一世可复制短码
- 终局页可复制短码
- 短码不含完整日志，只含姓名、境界、世界、年龄、结局、seed、道号、宗门、出身、灵根

## 灵界/仙界扩章

在现有两界四步主线之后各补 3 条余波：

- 灵界：西墙之后、旧部、边城春雪
- 仙界：雪线之后、仙官旧账、云海旧钟

不新增地图，不改变境界节奏。

## 边界

- 不做每日/每周任务
- 不做社交、排行、多人
- 不新增战斗系统
- 短码只读，不包含账号 Token 或完整日志
- 旧存档字段缺失时正常降级
