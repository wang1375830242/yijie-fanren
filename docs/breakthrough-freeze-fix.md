# 突破后页面卡顿修复

日期：2026-10-23  
状态：已修复

## 现象

冲击大境界后页面短暂卡住，但后台事件仍在继续流转。

## 原因

`openBreak()` 有两条路径：

- 手动点击「即刻冲关」
- 自动推演时自动选择

自动路径在 `sim.chooseBreak()` 后没有关闭 `#choiceOverlay`，也没有重置弹窗状态。于是突破已经完成、定时器继续推进事件，但玩家仍然看到一层拦截操作的遮罩，表现为“页面卡住，流程还在走”。

另外，化神→炼虚、大乘→真仙会改变 `world`，原路径只在下一回合的 `loop()` 里调用 `handleWorldChange()`，突破当下没有进入飞升过场。

## 修复

两条路径统一：

```text
关闭抉择遮罩
清理弹窗状态
结算突破
刷新界面
若世界改变，立即暂停并播放飞升过场
否则恢复自动推进
```

自动路径还补上了 `resetPromptChrome()`。

## 验证

```text
canon-regression: 293 checks passed
220 runs, 0 issues
```

新增源码回归：

- 突破路径必须关闭抉择遮罩
- 手动与自动路径都必须在跨世界破境时调用 `handleWorldChange()`
