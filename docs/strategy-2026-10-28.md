# 策略化改造（2026-10-28）

## 本轮落地

- 破境面板：显示基础成算、准备、伤势与最终概率。
- 破境准备：稳一稳增加 `breakPrep`，伤势降低成算和修炼速度，失败保留一部分准备。
- 风险：移除隐藏默认加成，非致命失败增加伤势。
- 道统：宗门成员可选择丹鼎 / 剑锋 / 阵心 / 游侠；法宝与体质可形成 0–2 级 Build。
- 性格：停止由资源自动抬高所有性格，改为选择显式增加；道统、法宝选项带 trait。
- 因果：新增 `karmaBook` 记录本世关键因果；结局继续使用因果标签。
- 传承：道果增加 `bequest` / `burden` 字段；下一世会被标记 `usedBy`，不能重复使用。

## 当前边界

- 碑林作者归属仍不属于本轮。
- 传承选择已接入终局页（道果/遗物/道统/因果），默认道果。
- 性格门槛与因果事件已接入基础版；恩人/仇人后续事件仍需继续扩展。
- 本命法宝现在通过 bond 温养，破境/剑匣事件增加共鸣；体质觉醒事件已接入；四道统各有一次专属事件。
