# P5：姓名性别匹配

日期：2026-10-23  
状态：已实现

## 问题

原来所有角色共用一个 `GIVEN` 名字池，主角、道侣、弟子、对手、同劫都可能出现“男性角色叫明显女性名”或反过来的情况。

另外，凡人角色在三十岁仍会收到「修行图什么」的问心事件，文案与身份不符。

## 命名方案

采用「男名池 + 女名池 + 中性名池」：

- `MALE_GIVEN`：约 37 个偏男性/英气的名字
- `FEMALE_GIVEN`：约 34 个偏女性/清丽的名字
- `NEUTRAL_GIVEN`：约 10 个中性名，保留少量模糊感
- `GIVEN`：三池合并，仅供旧代码兼容

规则：

- 主角先定性别，再从对应池取名
- 道侣默认取主角异性，并记录 `gender`
- 弟子、对手各自随机性别，再取对应池
- 同劫四人各自记录 `gender`
- 旧存档中的旧名字不修改，只影响新生成角色
- 不根据旧名字反推性别

## 顺带修正

- 凡人角色不再触发三十岁、五十岁、七十岁的修行问心
- 三十岁以后问心只对 `path === "cultivator"` 的角色开放
- 「婚事」与「孩子」事件里的「姑娘/妻子/男孩/他」改为中性表达，避免女角色触发时别扭

## 验收

- 50 个主角姓名的 given name 属于对应性别池
- 女性主角的道侣为男性名字
- 弟子、对手姓名匹配各自性别
- 同劫四人姓名匹配各自性别
- 旧名字不因新规则被改写
- 凡人三十岁不触发修行问心
- 修士三十岁仍正常触发
- 220 局回归无异常
