# P4：经济、无障碍与长局性能

日期：2026-10-23  
状态：第一版已实现

## 一、经济

### 高境界收入

`yearTick()` 现在按境界提高年收入：

```text
年收入 = focus.stones × (1 + max(0, tier - 1) × 0.18)
```

高境界每一步跨年更多，但灵石按年结算，不再只拿固定一份。

### 长期支出

新增年度维护：

- 灵脉洞府：每年维护
- 灵田：每年维护并产出灵石
- 弟子：按在世弟子发月例
- 灵界及以上：额外洞府维护

支出从年收入中扣除，不足时灵石归零，不产生负灵石软锁。

### 货栈

- 灵界丹 `tierMax` 从 8 放宽到 13
- 新增灵田商品
- 后期仙界仍有仙灵丹、仙宫玉简、护道仙符等商品

## 二、移动端与无障碍

## 三、性能

- 地图每 5 年或境界变化才重绘
- 生存曲线每 10 年才重绘
- `saveRun()` 自动保存最多每 1.5 秒一次
- `pagehide` 强制落盘，避免离开页面前丢进度
- `snapshot()` 仍保留完整状态，但不再每步深拷贝
