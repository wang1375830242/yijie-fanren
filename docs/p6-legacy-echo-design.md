# P6：再一世前世回响

日期：2026-10-23  
状态：最小版已实现

## 一、评审结论

可以开发，但第一版只做「轻回响」：

- 只有带前世道果的人生才会触发
- 每世最多一次，不写成“觉醒前世记忆”主线
- 不生成前世人物实体，只通过旧信、旧名、旧门牌、旧梦提及
- 不直接揭示前世死因，保留模糊感
- 旧道果缺少新字段时正常降级

## 二、道果新增字段

`legacySummary().source` 增加可选字段：

```text
place         前世出生地
sectName      前世宗门
partnerName   前世道侣姓名
discipleNames 前世弟子姓名（最多 3 个）
rivalNames    前世对手姓名（最多 2 个）
```

只保存可展示的名字，不保存完整关系对象；`v` 仍为 1，旧记录缺字段不会报错。

## 三、旧梦事件

事件：`legacy_echo`

触发：

- 人界
- 有 `s.legacy.source`
- 16 岁后
- 每世一次

文本按前世数据选择：

- 有道侣：陌生人送来署名前世道侣的旧信
- 有弟子：年轻修士打听前世弟子的名字
- 有宗门：旧衣铺里看见前世宗门门牌
- 都没有：梦见前世自己的名字

三个选择分别偏向记住、追问、烧掉，均写入 `legacy_echo_done`，不产生后续强制主线。

## 四、关系面板

关系面板从“只显示最后一个徒弟/对手”改为：

- 遍历全部 `s.disciples` 与 `s.rivals`
- 在世者在前，离世者在后
- 每条直接显示「在世」或「离世 · 寿尽」等状态
- 删除「在世 N/M」计数
- 已离世条目不删除，降低透明度并划线
- 关系列表限制高度，内容多时可滚动

## 五、验收

- 无前世道果不触发旧梦
- 有前世道果的 16 岁人生触发一次
- 旧梦结束后不会重复
- 道果记录前世道侣/宗门/弟子字段
- 三个徒弟、两个对手全部显示
- 删除「1/1 在世」计数
- 220 局回归无异常，单世重复 ≤ 2
- 事件总数 3085
