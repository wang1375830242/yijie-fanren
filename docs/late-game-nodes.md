# 后期重要节点：斩三尸与大乘/大罗之门

日期：2026-10-23  
状态：已实现第一版

## 一、口径说明

“斩三尸”在公开读者整理中常被放在**大罗到道祖之间**，但原著仙界篇对三尸的名称、顺序、失败规则存在不同概述。本项目采用：

> 大罗期内的三关，不是第十四重境界；细节为本作融合常见修仙设定与二创。

因此不新增 `tier`，不重排现有 14 个境界编号，避免破坏存档、道侣、碑林和事件条件。

## 二、斩三尸

在大罗期按修为分三段强触发：

| 顺序 | 事件 | 触发 | 选择 |
|---|---|---|---|
| 1 | `i_sanshi_e` 恶尸 | tier12，cult≥30 | 认下恶念斩 / 受一刀认债 / 止步大罗 |
| 2 | `i_sanshi_shan` 善尸 | tier12，cult≥60，已斩恶尸 | 斩善尸 / 留善念带伤过关 / 止步大罗 |
| 3 | `i_sanshi_wo` 自我尸 | tier12，cult≥90，已斩善尸 | 斩我 / 放逐进时空乱流 / 止步大罗 |

规则：

- 恶尸、善尸的“斩”是确定结算，代价是修为、心境、因果与悟性，不新增随机死亡
- 自我尸“斩我”有风险，失败直接死亡，`noRescue`，护身玉符不能挡
- 自我尸可放逐，必定成功但收益较低；也可止步大罗
- 任一步选择“止步大罗”写入 `sanshi_closed`，此生不再触发三尸与道祖之争
- 三尸全部完成才允许 `i_daozu`

## 三、大乘之门

- 事件：`i_dacheng_gate`
- 条件：灵界合体后期，cult≥85
- 作用：在正式突破大乘前给一次“叩门”选择
- 成功叩门写入 `dacheng_gate`，给 `breakBonus`/悟性；选择等待则不写 flag，仍可正常突破

## 四、大罗天

- 事件：`i_daluo_gate`
- 条件：仙界太乙后期，cult≥90
- 作用：在正式突破大罗前给一次“以法则/功德/等待”的选择
- 成功叩门写入 `daluo_gate`，给 `breakBonus`/悟性/因果
- 不影响 `canBreak`，不新增硬门槛

- 止步大罗后不再触发三尸/道祖
- 自我尸失败为硬死，玉符无效
