# 320px 与可访问性验收

日期：2026-10-23  
工具：Chromium headless + Playwright（Python），本地 `server.py`

## 320px 布局

在 320×900 视口逐页检查：

```text
index.html
play.html
hall.html
codex.html
about.html
changelog.html
```

结果：

```text
document.documentElement.scrollWidth === innerWidth === 320
```

六个页面均无横向溢出。

另外进入一局人生，检查顶栏、命运重心、人生录、三栏折叠与底部信息；`#log` 可见且宽度正常。

## 人生录可访问性

DOM：

```text
#log
role="log"
aria-live="polite"
aria-label="人生录，可用方向键滚动查看前情"
tabindex="0"
```

Chromium accessibility tree 中可读到：

```text
role: log
name: 人生录，可用方向键滚动查看前情
```

同时可见「切换人生录字号」按钮。控制台无 JavaScript 错误。

## 说明

本轮使用 Chromium 可访问性树验收，不是人工 Narrator/NVDA 朗读测试。若要发布前做最终无障碍验收，仍建议用真实读屏软件走一遍：
标题层级 → 开始此世 → 人生录方向键滚动 → 抉择按钮 → 字号切换。
