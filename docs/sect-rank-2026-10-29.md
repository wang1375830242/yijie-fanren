# 宗门职级与修为对应 · 2026-10-29

## 结论

旧规则把人界元婴/化神修士长期留在外门，不合理。原因是：

- 只有「外门、内门、执事、长老」四阶
- 长老要求化神，元婴最高只能到执事
- 晋升只依赖宗门贡献，且只有选择「宗门」重心才增长
- 缺少「大长老、太上长老」
- 灵界、仙界没有独立职级表

## 新规则

### 人界

| 职级 | 修为下限 | 说明 |
|---|---|---|
| 外门 | 炼气 | 入门弟子 |
| 内门 | 筑基 | 内门弟子 |
| 执事 | 筑基 | 负责具体事务 |
| 长老 | 结丹 | 峰主/长老级 |
| 大长老 | 元婴 | 元婴修士不再外门 |
| 太上长老 | 化神 | 宗门最高层/老祖 |

职级下限由境界保底，贡献只决定同境界内是否继续晋升。高境界不会因为没选「宗门」重心而掉回外门。

### 灵界

按界面职级上移：外门 → 内门 → 执事 → 长老 → 大长老 → 太上长老。境界对应炼虚、合体、大乘等。

### 仙界

仙官 → 执事 → 长老 → 大长老 → 仙君 → 掌教。高境界不再套用人界「外门弟子」称呼。
