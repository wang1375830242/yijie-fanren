# 《一介凡人》原著一致性与内容质量评审

> 评审日期：2026-10-23  
> 评审对象：`yijie-fanren` 当前版本（3090 条事件、100 组童年选择、95 位图鉴人物、45 个宗门/势力、18 条灵根/体质条目）
> 评审方式：GLM-5.3-Flash、MiniMax-M3.1-Flash、DeepSeek-V4.1-Flash、Space-Bunny 四个模型只读评审，再由主线程交叉核对。  
> 说明：原著细节存在读者分歧的地方，本文分为「原著冲突」「内部矛盾」「玩法不合理」「改编取舍」「待核对」，不把推测冒充原著明文。

## 一、结论

当前项目的主要问题不是“考据条目太少”，而是：

1. **数值和规则会拆掉世界观的台**：灵根、寿元、境界和死亡规则互相打架。
2. **图鉴数据和玩法脱节**：95 位人物、45 个宗门大部分只存在于图鉴，不影响游戏。
3. **人物界域/境界/结局标签不统一**：同一角色在 `data.js`、`canon.js`、碑林和 README 中有不同口径。
4. **事件数量真实，但组合重复感明显**：3090 条事件来自少量场景/细节/结果模板。
5. **部分文案有同人腔**：道侣文本里的 `ta`、把原著人物当随机碑、掌天瓶复制给玩家等。

## 九、道侣自动线（追加需求）

结为道侣后，partner 不再只保存名字和结伴年龄，而是有独立状态：

- `tier` / `cult` / `talent`：道侣自己修炼、突破
- `world` / `place` / `status`：同界、异地或决裂
- `affinity`：情分，随道侣事件中的选择变化
- `nextAt` / `maxAge` / `alive`：下一次突破时间、寿元和生死
- `partnerHistory`：寿尽后保留历史，不再直接丢失

行为：

- `partnerTick()` 随时间推进道侣修为、突破、世界迁移和寿尽。
- 同界时使用 `p_mortal / p_human / p_spirit / p_immortal` 日常事件；文本会显示道侣当前境界和状态。
- 异界时暂停日常事件，改为可重复的「两地书」事件，可回信、托人带旧物或闭关。
- 道侣突破、寿尽、异地会写入日志；关系面板显示「道侣 · 境界 · 所在界 / 异地」。

## 十、事件容量与千条扩展（2026-10-23）

评审判定：2064 条事件**不够**满足“同一世所有事件/对话最多重复 2 次”。

实测（220 局，可负担选项）：

- 单局平均事件约 27.6 条；长命高境界局约 70 条事件。
- 只看事件正文：220 局中 1 局最大重复 3 次。
- 事件正文 + 选择结果：220 局中 158 局有超过 2 次的重复，最大 11 次；瓶颈是选择结果文案，不是事件 ID 数量。
- 评委建议：不要只增加 ID；优先增加选择结果变体、场景池，并加入同世文本去重。

本次实施：

- 程序化事件 `N` 从 64 提升到 104，事件总数从 2064 增加到 **3090**（+1000）。
- 新增 `TEXT_CODAS` 阶段余韵池，选择结果重复时生成变体。
- `textUse` 记录同世事件/选择文本；事件选择过滤已出现 2 次的文本，选择结果重复时追加阶段余韵。
- 儿童场景、宗门场景、坊市场景补充了额外场景。
- 新验收：220 局中同世事件 + 选择文本最大重复必须 ≤ 2。

验收结果：

```text

220 runs, 0 issues
pseudo-spirit=7
worst-repeat=2

```

## 十三、转世道果

终局自动生成一份「道果」，下一世降生时自动继承，不做终局选择菜单：

- 灵根余韵：按前世灵根品阶只向上调整权重，不提高凡骨概率
- 悟性起点：按前世境界 +2~6，出生悟性上限 90
- 遗物：灵石余泽；前世化神以上额外带 1 枚护身玉符
- 未了因果：保留前世因果的正负方向，限制在 ±8

道果存独立的 `yijie.legacy.v1`，带版本号与世代深度；同一份道果只使用一次，境界、修为、寿元不继承。旧存档无道果字段时正常开局。

| 职位 | 贡献门槛 | 最低境界 | 每次结算灵石份额 |
|---|---:|---:|---:|
| 外门 | 0 | 炼气 | 5 |
| 内门 | 60 | 筑基 | 12 |
| 执事 | 180 | 结丹 | 25 |
| 长老 | 420 | 化神 | 50 |

- 选择「宗门」重心时，每步增加贡献；每次 step 的贡献有上限，避免高境界一步几百年瞬间升满
- 灵石份额按职位发放；散修、散仙、凡俗、杂役不进入职位体系
- 晋升时触发「宗门提拔」事件，事件排在里程碑与突破之后，不会覆盖已有 pending
- 角色标签、关系栏、终局摘要和碑林记录都会显示职位与贡献

## 十五、弟子与对手养成

弟子和对手不再只是名字，创建时补齐以下字段：

- 境界、修为、资质、年龄、寿元、下次突破时间
- 弟子亲厚值；对手敌意值
- 入世时间与当前状态

`afterStep` 中逐年推进：年龄随玩家同步增长，按需突破、刷新寿元；寿尽时标记离世、写入 `discipleHistory` / `rivalHistory`，并在日志中留一句收束。关系栏显示最近在世弟子的境界、亲厚和年龄，以及对手的境界、敌意和年龄。

为了不让两套系统空转，达到筑基/结丹节点时会自动结怨、收徒；原有收徒事件仍保留。所有推进均为确定性逻辑，不消耗玩家事件 RNG，也不创建 pending。

## 十六、后期节奏压缩

高境界不再一跳几百年：

- 炼虚到道祖的 `per` 从 40/80/160/400/800/1600/3200/9999 调整为 32/48/64/100/150/200/250/400 年
- 同时给高境界加 `pace` 修为补偿，避免拆段后变成数百次空点击
- 连续 2 步没有事件时，下一步事件率至少 0.45，保证灵界/仙界仍有抉择
- 道祖事件「退」会写入 `daozu_declined`，不会因 `seen` 永久卡死
- 低境界步长与原有节奏不变

## 十七、结局扩写与一生回顾

终局不再只有一句随机墓志铭：

- `finaleSummary()` 按死因族生成「证道 / 归尘 / 坐化 / 道消 / 劫尽 / 陨落 / 远行」等终局，并按因果给出「余庆 / 两清 / 业债」标签
- 道侣只作为终局修饰，不单独占用死因分类；有在世道侣或先走的道侣都会写进终局文本
- 终局页新增一段克制叙事，以及「来处 / 行路 / 归处」三幕回顾
- 三幕只取出生、人生中段、最后一条事件/破境，排除环境噪声和死亡日志；事件不足时允许少一幕
- `finale` 写入 summary，旧记录无该字段时仍使用原墓志铭路径

## 十八、道侣突破速度修正

道侣原实现按固定约 18 年一次、每次 +32～43 修为推进，没有按境界 `need` 缩放，导致高境界玩家一步数百年时，道侣几乎每步都能突破，千余岁即可到大罗/道祖。

修正后：

- 道侣突破间隔按自身境界的 `need / (talent × 1.2 × pace)` 计算，最低 20 年
- 每次到达间隔只做一次突破判定，失败后等待约半个间隔再试
- 道侣最高境界封顶 12（大罗），道祖仍是玩家专属的争位结局
- 保留随机成功/失败、寿元和跨世界迁移
- 本地 50 局复核：玩家 tier5 时，道侣在 1200 岁不再达到道祖；1200 岁通常仍为炼虚至合体
