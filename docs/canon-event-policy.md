# 致敬事件包规则

日期：2026-10-23  
状态：已启用，默认关闭

## 边界

本包只借《凡人修仙传》的世界名词，不复制原著正文，不改编具体剧情，不新增可攻略的原著人物。

允许：

- 黄枫谷、天南、天渊城、北寒仙域、乱星海等世界名词
- 以旧碑、旧砖、旧亭、旧渡口、茶棚等原创场景承载氛围
- 事件正文全部原创

禁止：

- 原著对白、段落、具体桥段
- 原著人物关系改写、结局改写
- 原著插图、动画形象
- 把事件伪装成原著原文

## 开关

关于页「你的数据」：

```text
启用致敬事件（只借世界名词，剧情全部原创）
```

偏好键：

```text
yijie.prefs.v1 / canonHomage
```

默认关闭。关闭后，致敬事件不会进入随机事件池。

## 事件字段

```js
{
  id: "homage_*",
  source: "homage",
  canonRef: "黄枫谷", // 只记录名词
  quote: "",         // 不引用原文
  review: "homage-only",
  when: (s) => enabled() && ...,
  text: "原创正文",
}
```

## 下架

删除 `js/canon-events.js` 的加载行，或把事件包的 `enabled()` 固定为 `false`，即可整包停用。

## 2026-10-29 原著资料核查流程

凡涉及《凡人修仙传》原著或世界观的内容（境界、宗门职级、人物、地域、时间线、称谓、战力、事件、设定等），先做资料核查，再评审方案：

1. **查来源**：优先 Weqoocu Wiki、百科、可追溯原文/可靠整理；记录 URL 与核查日期。
2. **分可信度**：
   - 原著明文
   - 读者整理 / Wiki
   - 二创改编
   - 争议 / 推测
3. **对照现状**：把资料和游戏当前数据、事件、UI 逐项对照，指出冲突点。
4. **先评审**：给出合理方案、影响范围和取舍，向用户简要汇报；不要直接凭模型记忆改代码。
5. **无依据时**：明确说“没有可靠来源”，按改编处理，不冒充原著定论。
