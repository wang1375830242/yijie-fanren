# 灵界、仙界主线

日期：2026-10-23  
状态：已实现

## 评审结论

- 灵界「天渊城西线」贴合原著灵界篇的异族战争与天渊城设定，采用四步链。
- 仙界「北寒仙域灰界裂隙」只使用原著世界名词（北寒仙域、灰界、断界海、仙宫），具体裂隙事件为二创，不冒充原著剧情。
- 不新增原著人物为主角，不使用原著正文，不改动既有大乘门、大罗门与斩三尸链。

## 灵界：天渊西线

四步：

1. `s_main_1` 西线烽火：异族拔除西墙阵眼，选择守墙、退守内城或带散修撤离。
2. `s_main_2` 阵眼将尽：修阵眼、填灵石或先护送凡人。
3. `s_main_3` 西墙失守：守缺口、走地道或点燃阵眼。
4. `s_main_4` 城下余烬：重建西城、刻碑或离开天渊城。

触发条件：

```text
world=spirit
tier 5–6
age >= 80
未完成 s_main_closed
```

奖励以军功、因果、少量突破加成为主，不直接赠送原著法宝。

## 仙界：北寒灰线

四步：

1. `i_main_1` 雪线裂缝：查看、封缝或卖消息。
2. `i_main_2` 灰潮：守雪线、护送南撤或用玉简暂封。
3. `i_main_3` 仙宫征召：进灰界、要求先撤凡人，或拒绝。
4. `i_main_4` 断界海的眼：以修为封眼、借潮水推回，或转身离开。

触发条件：

```text
world=immortal
tier 9–10
age >= 500
未完成 i_main_closed
```

限制在真仙至金仙，避开大罗门与斩三尸节点。
