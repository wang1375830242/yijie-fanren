# 道祖准备加成 · 2026-10-29

## 规则

新增 `daoPrep`，用于让前面的选择影响最终的道祖之争。

- 取值范围：`0 ~ 10`
- 显示为 `道祖准备 +X%`
- 只在 `i_daozu` 的风险判定中生效
- 总加成封顶 10%

## 来源

| 节点 | 选择 | 加成 |
|---|---|---:|
| 大乘之门 | 以自身道基硬叩 | +2 |
| 大乘之门 | 借雷云淬体 | +1 |
| 大罗天 | 以法则开路 | +2 |
| 大罗天 | 以功德叩门 | +1 |
| 斩恶尸 | 认下恶念，亲手斩它 | +2 |
| 斩恶尸 | 任它砍一刀，把债认下 | +1 |
| 斩善尸 | 斩去善尸 | +2 |
| 斩善尸 | 留下善念 | +1 |
| 斩自我尸 | 斩我 | +3 |
| 斩自我尸 | 放逐进时空乱流 | -3 |

`daoPrep` 不足 0 时按 0 处理；超过 10 时按 10 处理。

## 计算

道祖之争的风险公式在原有：

```text
基础 45%
+ 法宝风险加成
+ 气运修正
+ 重心修正
```

基础上增加：

```text
+ 道祖准备 / 100
```

最终仍限制在 `12% ~ 96%`。

例如：基础 45% + 道祖准备 10% = 55%。

## 显示

- 大罗期状态标签显示「道祖准备 +X%」
- 道祖之争事件文本会说明当前准备带来的成算
- 账号页每一世详情会显示该世留下的道祖准备

## 目的

- 前面的大乘/大罗关卡不只影响突破，也影响最终证道
- 「斩我」不再只是高风险低收益选项
- 「放逐」路线保留安全性，但道祖之争少 3% 成算
- 避免所有加成叠加后变成必成
