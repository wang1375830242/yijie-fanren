# 命运重心

日期：2026-10-24  
状态：已实现

## 六种重心

| 重心 | 主要收益 | 代价 |
|---|---|---|
| 苦修 | 修为 ×1.35 | 无灵石、无额外心境 |
| 游历 | 遇事率 ×1.5，风险成功 +3% | 修为 ×0.8，危险 +1 |
| 炼丹 | 灵石收入最高 | 修为 ×0.6 |
| 宗门 | 宗门贡献 +N/年 | 修为 ×0.7 |
| 参悟 | 心境 +2/年，8%/年悟性 +1 | 修为 ×1.0 |
| 蛰伏 | 心境 +4/年，危险 -1 | 修为 ×0.45 |

## 规则

- 炼气前不结算重心
- 炼气后每年结算修为、灵石、心境、悟性概率与遇事率
- `focus.luck` 影响风险选择成功率
- `focus.risk` 影响危险倾向与风险选择成功率
- 宗门贡献只在入宗后生效

## 显示

行动栏下方常驻：

```text
当前：修为 ×1.35 · 灵石 +0/年 · 心境 +0/年
```

宗门重心额外显示贡献；游历显示风险成功与危险；蛰伏显示降险。

## 验收

- 炼气前六个按钮禁用，文案为「炼气后开启」
- 切换重心后立即更新收益说明
- 同一 seed 下六种重心的结果有可辨别差异
- 320px 行动栏不溢出
- 不改变夜间/日间主题的显示
