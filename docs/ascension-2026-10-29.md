# 化神飞升灵界的境界问题 · 2026-10-29

## 结论

**化神后期飞升灵界后变成化神初期，不合理。**

飞升是界面跨越，不是重修同一个小境界。化神修士通过空间节点进入灵界后仍是化神，不应因为换界把「后期」重置为「初期」；之后才在灵界继续积累，突破到炼虚。

## 资料核查

- [飞升](https://www.weqoocu.cn/fanren-wiki/concept/fei-sheng.html)：说明飞升是人界修士进入灵界/仙界的境界突破，但来源未给出统一的详细流程。
- [灵界](https://www.weqoocu.cn/fanren-wiki/entity/ling-jie.html)：灵界是化神修士偷渡/飞升后的高阶界面；化神进入灵界后仍按化神境界继续修行。
- 游戏内部原注释也写明「穿过空间节点后仍是化神，炼虚要在灵界重新突破」。

因此这里按「换界不回退小阶段」处理；原著没有可靠依据支持化神后期飞升后跌回化神初期。

## 代码原因

`ascendTo("spirit")` 原先执行：

```js
s.tier = 5;
s.cult = 0;
```

`displayRealm()` 根据 `cult` 判断初期/中期/后期，所以：

```text
飞升前：化神后期（cult >= 67）
飞升后：化神初期（cult = 0）
```

## 修复

飞升灵界时保留当前 `cult`，限制在合法范围：

```js
s.tier = 5;
s.cult = Math.max(0, Math.min(99, Number(s.cult) || 0));
```

只在大境界变化时进入新境界的初期；同境界换界不重置小阶段。

## 回归

- 化神后期飞升后仍显示「化神 · 后期」
- 仍可继续突破到炼虚
- 仙界飞升仍从真仙初期开始，因为这是进入新的大境界
