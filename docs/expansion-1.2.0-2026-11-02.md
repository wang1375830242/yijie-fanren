# 1.2.0 扩展 · 挑战、道统与谱系

日期：2026-11-02

## P0 · 命格挑战

首版 10 个挑战，固定命格与 seed：

| 挑战 | 条件 |
|---|---|
| 凡骨筑基 | 无灵根出身，达到筑基 |
| 散修飞升 | 不入宗门，从人界飞升灵界 |
| 寒门大长老 | 山村/农家/猎户/渔村/矿工出身，达到大长老或太上长老 |
| 不借前尘 | 不继承前世道果，成为道祖 |
| 四道归一 | 同一账号体验四条道统 |
| 十世问道 | 账号累计完成十世 |
| 三界行 | 人界、灵界、仙界都经历过 |
| 大器晚成 | 二百岁以后首次筑基 |
| 本命三阶 | 本命法宝温养至三阶 |
| 飞升仙界 | 从下界飞升仙界 |

实现方式：

- 出生页选择挑战
- 挑战固定 seed，不使用前世道果
- 终局判定并写入账号
- 只记录完成时间，不给数值加成
- 账号页展示 `X / 10`

## P1 · 四道统中期事件

新增 32 条原创事件：

- 剑锋 8 条
- 丹鼎 8 条
- 阵心 8 条
- 游侠 8 条

触发条件：

```text
人界 + 筑基至元婴 + 对应 sectPath
```

每条事件只触发一次，权重 3，不进入炼气期事件池。

## P2 · 谱系深化

- 账号页新增「谱系」时间线，展示最近二十世的姓名、境界、结局、宗门、道侣、弟子与遗愿
- 转世旧梦从单一事件扩展为 6 种变体：
  - 道侣旧信
  - 弟子旧名
  - 仇敌旧事
  - 宗门旧门牌
  - 旧地
  - 旧梦
- 一局最多一次，不替代主线，不直接揭示前世死因

## 边界

- 不做社交、排行、多人
- 不扩灵界/仙界章节
- 挑战不影响修为、气运、战斗数值
- 旧存档缺少字段时按默认值降级
- 成就、挑战、谱系都随账号快照并集同步
