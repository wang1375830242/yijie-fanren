# 账号与云存档（2026-10-28）

## 当前范围

- 游客仍可完整游玩，不需要登录。
- 账号为可选功能：注册 / 登录 / 退出 / 恢复码。
- 登录后同步最近 60 世、当前人生、legacy、lineage、碑林阅读记录和灯数。
- 留言板登录后使用账号显示名，只能删除自己的留言。
- 碑林留言已支持登录账号显示名与删除自己的留言；旧匿名留言保持匿名。

## 传输方式

当前采用用户选择的 **GitHub Pages + Bearer Token** 方案：

- token 存在本机 `localStorage`，请求带 `Authorization: Bearer ...`
- 服务端只保存 token 的 SHA-256 哈希
- 密码使用 scrypt + 每用户随机盐
- 没有邮箱找回；注册时生成一次性恢复码

这是一个有明确取舍的方案。GitHub Pages 没有统一 CSP，token 一旦遇到 XSS 就可能被盗；长期建议迁移到自有域名同源部署，改用 HttpOnly Cookie。

## 数据合并

登录时：

1. 读取云端 snapshot
2. 与本机 snapshot 合并
3. `lives` 按 id 去重，`steles` 取并集，`candles` 取每座最大值
4. 用 `baseRevision` 提交；冲突返回 409，客户端合并后重试
5. 首次登录会记录本机 owner；换账号不会自动上传上一个账号的本地数据

当前云端只保留本机最近 60 世，这是现有本地存储上限，不是“无限归档”。

## 边界

- 不保存密码明文、不对外暴露用户名。
- 账号不迁移碑林留言作者；碑林迁移另开阶段。
- 账号注销、密码修改后的会话撤销、完整备份恢复尚未完成，属于后续阶段。
