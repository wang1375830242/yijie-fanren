# 1.3.3 · 身世、誓约与时代

日期：2026-11-11

## 身世底牌与错认

每世降生时暗置一张身世底牌：

- 弃婴
- 罪宗之后
- 妖族血脉
- 被顶替的遗孤

底牌不直接显示。十八岁前后会遇到一次“错认”：有人把你认成另一个人。承认、否认、追问旧物，会把身世线索推进到下一阶段。五十五岁后可以追到真相。

结局页只有在真相揭开后才显示“身世”；没有揭开则保留“未明”。

## 自缚誓约

玩法合集新增可选誓约：

- 不杀生
- 不拜师
- 不结丹

誓约只改变事件和后果，不发数值奖励、不做完成度、不做难度排名；玩法合集同时收纳命格挑战与自由降生。

三十五岁前后会触发一次誓约试炼。选择破誓会：

- 标记 `oathBroken`
- 心境下降
- 获得一层道心裂痕
- 增加伤势

不直接掉境界，也不直接死亡。

## 时代相位

每世随机一个时代：

- 承平
- 兵灾
- 末法
- 灵潮

时代只影响：

- 修炼速度的小幅修正
- 一段时代事件
- 页面上的时代标签与结局记录

不做每日/每周时代任务，不把时代做成战力天梯。

## 1.3.3 追加：散修野路与高境瓶颈

- 人界散修在筑基后触发一次「野路问道」；只开放游侠道统，器胚改用坊市旧货摊文案。
- 不复制丹、剑、阵三条宗门道统，宗门道统仍只属于宗门。
- 元婴→化神增加 `breakForecast` 窄瓶颈 `-0.40`；寿元与后期节奏不动。
- 旧存档不需要迁移；已过筑基的散修下次 `afterStep` 补触发，已立道统不重复。

## 1.3.3 追加：故人回身

- 旧人只从实际选择写入，不从会被截断的 `choiceTrace` 反查；一生最多记录 3 人。
- 实际回归一生最多 1 人；不显示待回归、好感度或人情倒计时。
- 散修、宿敌可本人重逢或隔界来信；采药人按凡人寿命结算，由后人代来，不强行复活。
- 回归只给轻微心境、因果或悟性变化，不给法宝、突破、护命或大额资源。
- 旧存档缺少 `oldFriends` 时静默关闭旧人线，不提升存档版本。


旧存档缺少字段时补默认值，不提升存档版本号。
