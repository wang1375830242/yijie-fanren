# 1.3.3 · 身世、誓约与时代

日期：2026-11-11

## 身世底牌与错认

每世降生时暗置一张身世底牌：

- 弃婴
- 罪宗之后
- 妖族血脉
- 被顶替的遗孤

底牌不直接显示。十八岁前后会遇到一次“错认”：有人把你认成另一个人。承认、否认、追问旧物，会把身世线索推进到下一阶段。五十五岁后可以追到真相。

结局页只有在真相揭开后才显示“身世”；没有揭开则保留“未明”。

## 自缚誓约

玩法合集新增可选誓约：

- 不杀生
- 不拜师
- 不结丹

誓约只改变事件和后果，不发数值奖励、不做完成度、不做难度排名；玩法合集同时收纳命格挑战与自由降生。

三十五岁前后会触发一次誓约试炼。选择破誓会：

- 标记 `oathBroken`
- 心境下降
- 获得一层道心裂痕
- 增加伤势

不直接掉境界，也不直接死亡。

## 时代相位

每世随机一个时代：

- 承平
- 兵灾
- 末法
- 灵潮

时代只影响：

- 修炼速度的小幅修正
- 一段时代事件
- 页面上的时代标签与结局记录

不做每日/每周时代任务，不把时代做成战力天梯。

## 兼容


旧存档缺少字段时补默认值，不提升存档版本号。
