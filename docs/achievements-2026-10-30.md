## 判定

- 账号级，不是单世成就
- 一世结束时统一结算
- 使用 `endSummary`、`lives`、`lineage.total` 与成就元数据
- 旧存档首次加载时静默补算，不重复弹提示
- 判定幂等，重复读档不会重复解锁

## 展示

### 账号页

新增成就墙：

- 总数 `X / 18`
- 按分类展示
- 解锁时间
- 未解锁条件
- 隐藏成就占位

### 终局页

显示「此世新成就」，只列本世新解锁的成就，不打断终局阅读。

### 游戏内

- 普通成就不弹窗，只在终局和账号页展示
- 稀有成就使用非阻断 toast：`成就解锁 · 证道`
- 多个成就排队，不打断选择、突破和飞升动画

## 存储与同步

- 本机键：`yijie.achievements.v1`
- 结构：`{ v: 1, items: { [id]: { at } } }`
- 加入账号快照
- 多设备合并取并集
- 同一成就保留最早解锁时间
- 旧快照缺字段时不清空本机成就

## 边界

- 不展示账号 ID、Token、IP、原始日志
- 不做成就排行
- 不让成就影响游戏数值
- 不用最近 60 条 `lives` 判断累计世数，累计世数以 `lineage.total` 为准
